# INTELL Form Reference

## Onboard Lead Form

The public onboard form captures interested users before or during manual onboarding.

Fields:

- `firstName`
- `lastName`
- `email`
- `phoneNumber`
- `state`
- `inverterType`
- `interest`
- `source`
- `message`

Use shadcn `Select` for `state`, `inverterType`, `interest`, and `source`.

Current source options:

- LinkedIn
- Instagram
- Twitter (X)
- Google
- WhatsApp
- Friends or colleagues
- Installer referral

## Feedback Form

The dashboard settings feedback form should keep account identity fields read-only. Users should submit category, priority, and message content only.

## Super-Admin Communication Form

Broadcast creation should feel like composing a message:

- Subject
- Audience
- Action button label/type
- Action URL
- Message body
